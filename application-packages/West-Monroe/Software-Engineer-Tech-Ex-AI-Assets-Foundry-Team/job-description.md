Software Engineer- Tech Ex AI Assets Foundry Team
Chicago; Dallas; Los Angeles; Minneapolis; New York; San Francisco; Seattle; Washington, D.C.
Are you ready to make an impact?

West Monroe is seeking a Software Engineer to join the AI Assets Foundry Team, working with the internal Labs product team to develop proprietary software assets and AI capabilities that help our consultants sell and deliver more effectively and efficiently. This is an internal product engineering role focused on building reusable, scalable, secure AI-enabled applications and platform components in partnership with product owners, designers, architects, senior engineers, governance, and engineering teammates. 

Responsibilities: 

Develop, test, deploy, and support full-stack software features and reusable asset components for the Tech Ex AI Assets portfolio. 
Implement Generative AI-enabled capabilities within software products, including API integrations, prompt workflows, retrieval-augmented generation patterns, and data-driven features under the guidance of senior engineers and architects. 
Translate product requirements, user stories, and acceptance criteria into clean, maintainable, and secure code in collaboration with product owners, product design, and engineering teammates. 
Participate in Agile ceremonies and contribute to iterative delivery, estimation, backlog refinement, sprint planning, demos, and retrospectives. 
Follow established architecture patterns, coding standards, security practices, and responsible AI guidance while contributing practical engineering input during design discussions. 
Contribute to engineering quality through unit testing, integration testing, code reviews, documentation, CI/CD practices, and defect resolution. 
Troubleshoot application issues across front-end, back-end, data, cloud, and AI service layers with support from senior team members when needed. 
Collaborate with distributed engineering, product, governance, and product success partners to improve internal software assets and drive adoption by West Monroe consultants. 
Continue building depth across modern software engineering, cloud development, data integration, and AI-enabled application development practices. 

Core Technologies: 

Back-end: Node.js, Python, .NET 
Front-end: React, TypeScript, JavaScript, HTML5, CSS3 
Database / Data: PostgreSQL, MongoDB, SQL Server, data integration patterns, and exposure to vector search or embedding stores where applicable 
Cloud: Microsoft Azure, Amazon Web Services (AWS) 
Generative AI: Azure OpenAI, Databricks Machine Learning, LLM integration, prompt engineering, embeddings, retrieval-augmented generation, and AI evaluation concepts 

Patterns & Tools: 

Patterns: REST APIs, MVC, MVVM, service-oriented architecture, event-driven patterns, and microservice concepts 
Source Control / Delivery: Git, Azure DevOps, pull requests, branching strategies, and CI/CD pipelines 
DevOps Tooling: Terraform, Docker, infrastructure as code, environment configuration, and deployment automation 
Package Management: npm, NuGet 
Testing / Quality: Jest, unit testing, integration testing, code review, static analysis, and defect triage 

Qualifications: 

Bachelor's degree in a relevant field preferred, or equivalent experience required. 
2+ years of experience in full-stack software development or comparable hands-on application development experience. 
Working knowledge of object-oriented concepts, software design principles, algorithms, data structures, and common design patterns. 
Hands-on experience with modern application development using APIs, databases, front-end frameworks, back-end services, and source control practices. 
Exposure to cloud services, CI/CD delivery practices, automated testing, and modern DevOps ways of working. 
Interest in and practical exposure to AI, machine learning, Generative AI, or data-driven software capabilities; experience with Azure OpenAI, Databricks, LLM APIs, RAG, embeddings, or model evaluation is preferred but not required. 
Comfortable working within a fast-paced, collaborative Agile/Scrum product environment with product owners, designers, architects, senior engineers, governance, and product success partners. 
Able to follow architecture direction, ask thoughtful technical questions, and make steady contributions to hands-on asset development without owning architecture decisions. 
Strong problem-solving, debugging, communication, documentation, and learning skills. 
Strong English communication skills and ability to work effectively with distributed teams across geographies and time zones. 
Smart, versatile, and passionate about delivering high-quality code while continuing to grow across technologies and languages
