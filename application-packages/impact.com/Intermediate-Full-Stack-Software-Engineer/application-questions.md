# Application Questions

## Required Interactive Data Visualization Question

- Prompt from the live Greenhouse application form: Describe a specific project where you helped build interactive data visualizations. What was your role, and what technologies did you use?

I would use Travel Health Advisor as the example. I built the React/Vite frontend pieces for an interactive country-selection map and connected them to an Express and MongoDB backend that returned disease and vaccine data by country. My role was to make the data useful to a person planning travel, not just display raw records. The map used D3 and TopoJSON through React mapping libraries, and the interface surfaced risk level, vaccine availability, healthcare access, and recovery-rate details. I also worked on the surrounding JavaScript, HTML, and CSS behavior so the visualization felt like part of the product workflow.
