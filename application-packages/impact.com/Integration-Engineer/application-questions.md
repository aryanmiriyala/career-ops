# Application Questions

## Interactive Data Visualization Project

Prompt - Describe a specific project where you helped build interactive data visualizations. What was your role, and what technologies did you use?

One example is Travel Health Advisor, a hackathon project where I helped build an interactive travel-health tool. The main visualization was a world map where users could select a country and see health-related data tied to that location, such as disease risk, vaccine availability, healthcare access, and recovery-rate information.

My role was on the full-stack implementation. We researched a Kaggle dataset, cleaned and structured the data, added it to MongoDB, and connected it to the frontend through Express and REST APIs. On the frontend, we used React, Vite, react-simple-maps, D3, and TopoJSON to make the map interactive instead of showing the data as a static table.

We also built a lightweight RAG chatbot that used the health information the user provided, along with their selected country, to give more relevant travel-health guidance. It helped turn the visualization into something more useful because users could ask questions based on their own situation instead of only reading general country-level data.
