## Relevant Findings

- Smartsheet positions itself as an enterprise work-management platform used by a large enterprise customer base, including 85% of the Fortune 500.
- Smartsheet's careers page says applicants may apply to a maximum of three roles within a 90-day period. This would be Aryan's second Smartsheet package from August 3, 2026, so it remains within that limit.
- Public Smartsheet role pages and the pasted posting emphasize remote-eligible U.S. engineering work, AWS/cloud infrastructure, distributed systems, scalable services, code reviews, architecture discussions, product collaboration, and AI-assisted development.
- The current pasted posting is materially more senior than the Software Engineer I package: it asks for 2+ years, Java/Kotlin or TypeScript, 2+ years cloud, mentoring junior engineers, and highly scalable/highly available applications.
- Third-party sponsor-history data from Ellis reports recent Smartsheet H-1B filings, including Software Engineer I/II records. This is useful risk context but not a guarantee that this role supports future sponsorship.
- E-Verify/USCIS guidance confirms STEM OPT extension employment requires E-Verify participation and Form I-983 support. The pasted posting does not confirm those items, so they remain recruiter follow-up questions.

## Package Implications

- Use exact role language only where truthful: Software Engineer II - Full Stack (Remote Eligible), TypeScript, REST APIs, AWS, distributed systems, code review, architectural discussions, mentoring, cloud infrastructure, AI-assisted development, and troubleshooting.
- Do not claim Kotlin, Java, Kubernetes, Azure production experience, or direct Smartsheet-scale high-availability SaaS ownership.
- Include BGSU GRA mentoring evidence to partially address the mentoring requirement without claiming professional junior-engineer mentorship.
- Submitted artifacts should not mention F-1, OPT, STEM OPT, sponsorship, E-Verify, or Form I-983.
