# Funnel Leasing Inc. - Software Engineer L1 (Entry to Mid-Level)

## Job Description

Funnel Leasing Inc., is hiring for a Software Engineer L1 (Entry to Mid-Level) that can 'work from anywhere' in the U.S. The Software Engineer L1 will be an Entry to Mid-Level Software Engineer to help build and maintain our software products. You'll work closely with experienced engineers, product managers, and designers to develop your skills and contribute to impactful projects. If you have a strong foundation in computer science, a passion for learning, and problem-solving skills, we'd love to hear from you. The salary range for this role is $70,000 - $90,000 per year.

### The Software Engineer L1 essential roles and responsibilities include, but are not limited to the following:

**Roles and responsibilities:**

- Write clean, maintainable, and efficient code to develop new features for Funnel's software products.
- Write unit tests and end-to-end tests to ensure software reliability and quality.
- Troubleshoot bugs and contribute to improving software performance, scalability, and reliability.
- Leverage modern development tools, including AI-assisted coding tools, to improve productivity and streamline development workflows.
- Participate in code reviews and design discussions to improve your skills.
- Continuously learn and adopt new technologies, tools, and software engineering best practices.
- Collaborate with cross-functional teams to deliver high-quality software.
- Travel: <5%

**Education, Work Experience, and Certifications**

- Bachelor's degree in Computer Science, Software Engineering, or related experience.
- 0-2 years of software engineering experience, including relevant internships or hands-on projects.
- Professional experience in Python (Django) for backend development and JavaScript (React) for frontend development.
- Understanding of web technologies, including REST APIs, HTTP, HTML, and CSS.
- Familiarity with modern software development practices, including version control, testing, debugging, and code reviews.
- Comfortable using AI-assisted development tools (such as GitHub Copilot, Cursor, Claude Code, or similar) while applying sound engineering judgment to evaluate their outputs.
- Strong communication, collaboration, analytical thinking, and problem-solving skills.
- Eagerness to learn and grow in a fast-paced, evolving engineering environment.
