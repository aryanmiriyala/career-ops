## About the Hiring Group

We are seeking an Early-Career Software Engineer who is excited about building the next generation of AI-powered applications and research solutions.

This role is ideal for someone with strong software engineering fundamentals who wants to grow into an AI-native engineer. You will work alongside experienced engineers to design, build, and deploy production systems that leverage large language models (LLMs), retrieval-augmented generation (RAG), AI agents, cloud services, and modern software engineering practices.

Success in this role requires curiosity, sound engineering judgment, and a desire to continuously learn as AI technologies evolve.

This position may be based remotely within the United States. Candidates located near RTI's headquarters in Research Triangle Park, North Carolina, are preferred due to opportunities for in-person collaboration.

## What You'll Do

Working with senior engineers and research data scientists, you will:

- Develop production software using Python and modern development frameworks.
- Build AI-powered applications using large language models and AI APIs.
- Help develop retrieval-augmented generation (RAG) pipelines and agent-based workflows.
- Build and consume REST APIs and cloud-native services.
- Write clean, maintainable, well-tested code using AI coding assistance like Claude Code and GitHub Copilot CLI.
- Participate in code reviews and architectural discussions.
- Assist with deployment, monitoring, and troubleshooting production applications.
- Learn how to evaluate AI systems for quality, accuracy, reliability, and cost.
- Work with researchers and technical staff to understand requirements and translate ideas into software solutions.
- Contribute to improving development standards, documentation, and engineering practices.
