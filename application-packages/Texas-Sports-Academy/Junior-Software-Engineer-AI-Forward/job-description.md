## Description

As a Junior Software Engineer with Texas Sports Academy, you will help build the software that runs the school, student records, academic mastery tracking, training data, parent portals, admissions, and the AI-powered tools guides and coaches use every day. This is an early-career, AI-forward seat. The engineer will work directly with founders and senior engineers, ship code every week with AI in the loop, and grow into the LLM-powered features that make the school feel unlike a traditional school.

## What You Will Be Doing

- Building and shipping product features across the full stack every week, with AI coding tools running alongside you.
- Contributing to real LLM-powered product features: tutoring agents, parent-facing copilots, coach-facing dashboards, retrieval over student data, and the evals behind them.
- Working directly with founders and senior engineers on scope and trade-offs, with no PM layer in between.
- Picking up ownership of smaller systems end-to-end and growing into bigger ones.
- Running your own AI coding workflow, prompts, subagents, custom tools, MCP servers, and improving it every week.
- Writing evals and regression tests for AI features the same way unit tests are written for classical code.

## What You Will Not Be Doing

- Pretending AI is optional. The posting says candidates should already be coding with Claude Code, Cursor, Codex, or an equivalent agent loop.
- Sitting in status meetings all day.
- Working on a narrow slice of a giant codebase.
- Waiting around for tickets.

## Key Responsibilities

- Ship production code and AI features that real students, parents, and staff rely on every day.
- Own smaller systems and features end-to-end while ramping up.
- Move features from idea to production in days without breaking things.
- Level up AI-engineering skill alongside a senior team.

## Requirements

- Bachelor's or master's degree in Computer Science, Engineering, Math, or Physics.
- Based in Austin, TX or within commuting distance.
- 0 to 2 years of full-time engineering experience. Strong internships, side projects, and shipped personal work count.
- Daily, fluent use of AI coding tools such as Claude Code, Cursor, Codex, Windsurf, Aider, or equivalent as the default way of writing software.
- Comfortable in a modern web stack, such as TypeScript / React / Node or Python / Postgres / AWS or GCP.
- Excellent written English.

## Nice To Have

- At least one shipped LLM-powered project, school project, hackathon, or side project with an eval story.
- Agent frameworks such as LangGraph, CrewAI, Mastra, or custom frameworks.
- Vector search / RAG.
- Evals such as Braintrust, LangSmith, or custom evals.
- Prompt caching.
- MCP servers.
- Structured output / tool-use.
- Voice agents.
- Public GitHub or a personal AI project the company can try.
- A personal project built because the candidate wanted to build it.
- Background in education, edtech, or sports.

Texas Sports Academy is an Austin-area school model for student-athletes. Public company materials emphasize personalized learning, mastery-based progression, a compressed academic schedule, sports training, life skills, coaches/guides, and AI-powered learning support.
