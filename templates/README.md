# Templates

Reusable scaffolds for application packages and outreach.

- `reusable-application-prompt.md`: intake wrapper for starting a new application-package chat. It should stay compact and defer workflow authority to `AGENTS.md`.
- `job-description-template.md`: package-local posting shell. Preserve the full employer posting and add only compact metadata, extracted keywords, eligibility notes, and initial plan fields.
- `tailoring-notes-template.md`: package-local audit record for resume direction, keyword map, gap recovery, F-1 gate, bullet audit, scoring, validation, and token-efficient source access.
- `expanded-keywords-template.txt`: package-local exact-term list format for expanded analyzer runs.
- `referral-outreach-template.md`: short referral, recruiter, hiring-manager, and coffee-chat message guidance.
- `canonical-resume.tex`, `canonical-cover-letter.md`, and `canonical-visual-system.md`: source/layout standards for submitted artifacts.

Keep templates aligned with `AGENTS.md`, `profile/ats-recruiter-resume-guide.md`, `profile/resume-targeting-guide.md`, and `automation/validate_application_package.py`. If a pipeline rule changes, update the relevant template in the same maintenance pass.
