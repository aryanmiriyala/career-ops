# Canonical Application Visual System

Use these files as the visual source of truth for application packages:

- Resume source: `templates/canonical-resume.tex`
- Cover-letter source: `templates/canonical-cover-letter.md`

## Resume

- US Letter, 11-point `article` class.
- Computer Modern typography.
- Approximately 0.22-inch left/right margins and 0.10-inch top/bottom margins.
- `\linespread{0.92}`.
- Centered name/contact block.
- Small-caps section headings with divider rules and a visible 2-point gap.
- Single-column, text-only layout.
- One consistent raised 10-point solid round bullet marker.
- No `tabular`, images, icons, headers, footers, text boxes, or multi-column sections.
- Use the canonical `tightitemize` single-level bullet list.

## Cover Letter

- 11-point Computer Modern typography.
- Approximately 0.80-inch left/right margins and 0.70-inch top/bottom margins.
- Same name/contact hierarchy as the resume family.
- Standard date, addressee, salutation, body, and signature order.
- No decorative graphics.

## Review Rule

Check new artifacts against this canonical system and the validator output. Do not open prior application packages solely for visual comparison.
