# Operations

Application status and referral tracking.

- `application-tracker.md`: high-level tracker for applications, outcomes, referral status, and follow-up status.

Status updates should be entered manually in `application-tracker.md`.

Referral fields should be populated for every application:

- `Referral Status`: `Not started`, `Researching`, `Outreach drafted`, `Outreach sent`, `Followed up`, `Referral requested`, `Referral submitted`, `No referral available`, or `Declined`.
- `Referral Target / Source`: employee, alumni, recruiter, hiring manager, founder, professor, mutual contact, or source link.
- `Next Referral Follow-up`: date or `TBD`.
